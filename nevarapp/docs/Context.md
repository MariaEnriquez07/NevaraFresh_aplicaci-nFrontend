# NevaraFresh — Aplicación de domicilios

## Qué es

NevaraFresh es un proyecto orientado a la comercialización y distribución de productos frescos. Esta aplicación corresponde exclusivamente al sistema de domicilios dirigido a los clientes, desde el cual podrán explorar los productos disponibles, consultar sus detalles, seleccionar lo que desean comprar y gestionar sus pedidos.

La aplicación busca ofrecer una experiencia de compra sencilla, clara y accesible, permitiendo que los clientes encuentren productos, organicen su compra y conozcan el estado de sus pedidos.

## Alcance de la aplicación

La aplicación se centra en el proceso de compra y entrega a domicilio para clientes.

- Explorar y consultar el catálogo de productos.
- Visualizar información y detalles de cada producto.
- Seleccionar productos y gestionar las cantidades deseadas.
- Administrar un carrito de compras.
- Registrar o seleccionar una dirección de entrega.
- Revisar el resumen de la compra antes de confirmar el pedido.
- Consultar los pedidos realizados y sus estados.
- Acceder a la información básica del perfil del cliente.

El alcance definitivo de cada funcionalidad se definirá progresivamente durante el desarrollo del proyecto.

## Qué no incluye

Esta aplicación no corresponde a los sistemas internos de administración, gestión de inventario, operación logística ni gestión de proveedores de NevaraFresh.

Tampoco representa una aplicación independiente para repartidores. Su propósito es atender las necesidades del cliente que realiza compras y solicita entregas a domicilio.

Los procesos internos que puedan relacionarse con los pedidos pertenecen a otros componentes del proyecto y no deben confundirse con las funcionalidades propias de esta aplicación.

## Tecnología

- Aplicación desarrollada con Flutter y Dart.
- Interfaz adaptable a las plataformas objetivo del proyecto.
- Organización del código orientada a la reutilización y al mantenimiento.
- Modelo de datos documentado de forma independiente a las pantallas.
- Integración con servicios externos y persistencia de datos según las decisiones técnicas del proyecto.

## Organización del proyecto

La estructura del proyecto se establecerá y ajustará conforme avance el desarrollo de la aplicación.

Se busca mantener una separación clara entre las pantallas, los componentes reutilizables, los modelos de datos y la lógica necesaria para gestionar las funcionalidades de la aplicación.

La documentación del modelo de datos deberá mantenerse separada de la implementación visual para facilitar la evolución progresiva del sistema.

## Criterios generales

- La aplicación debe priorizar una experiencia de compra clara y sencilla.
- Las funcionalidades deben corresponder al alcance de la aplicación de domicilios.
- Las pantallas deben representar procesos coherentes con el recorrido del cliente.
- La información presentada debe corresponder al modelo de datos definido para el proyecto.
- No se deben asumir funcionalidades, atributos o reglas de negocio que todavía no hayan sido establecidos.
- Las decisiones de diseño e implementación deben permitir ampliar la aplicación progresivamente.
- La interfaz debe mantener consistencia visual y funcional entre sus diferentes pantallas.
- Las decisiones relacionadas con pagos, disponibilidad, entregas, autenticación e integración de servicios se definirán conforme se establezcan los requisitos correspondientes.

## Estado del proyecto

NevaraFresh se encuentra en una etapa de desarrollo progresivo. Este contexto establece la identidad y el alcance general de la aplicación de domicilios, pero no constituye una especificación funcional definitiva.

Las funcionalidades detalladas, el modelo de datos, la navegación, las reglas de negocio y las decisiones de arquitectura se definirán a medida que avance el proyecto.
